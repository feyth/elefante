## Como usar em um novo projeto Next.js

### 3 passos. Nada mais.

**Passo 1 — Copie**
Copie TODO o conteúdo desta pasta para a raiz do novo projeto Next.js.

```
seu-projeto-next/      ← raiz do projeto
├── .elefante/         ← vem do .mestre-nextjs
├── .agents/           ← vem do .mestre-nextjs
├── INICIAR.md         ← vem do .mestre-nextjs
└── README-ELEFANTE.md ← vem do .mestre-nextjs
```

**Passo 2 — Abra o projeto na IA e mande:**
```
leia INICIAR.md
```

**Passo 3 — Programe**
A IA detecta o `package.json`, lê a stack Next.js/TypeScript, preenche tudo sozinha e avisa quando está pronto.
A partir daí, use `#elefante` no início de cada prompt.
