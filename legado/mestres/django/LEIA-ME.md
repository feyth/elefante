## Como usar em um novo projeto Django

### 3 passos. Nada mais.

**Passo 1 — Copie**
Copie TODO o conteúdo desta pasta para a raiz do novo projeto Django.

```
seu-projeto-django/    ← raiz do projeto
├── .elefante/         ← vem do .mestre-django
├── .agents/           ← vem do .mestre-django
├── INICIAR.md         ← vem do .mestre-django
└── README-ELEFANTE.md ← vem do .mestre-django
```

**Passo 2 — Abra o projeto na IA e mande:**
```
leia INICIAR.md
```

**Passo 3 — Programe**
A IA detecta o `requirements.txt` ou `pyproject.toml`, lê a stack Django, preenche tudo sozinha e avisa quando está pronto.
A partir daí, use `#elefante` no início de cada prompt.
