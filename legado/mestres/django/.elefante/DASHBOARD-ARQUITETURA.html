Workflow de Requisição

1
Cliente faz requisição HTTP
Browser/API envia GET/POST para uma rota específica
2
Middleware processa
Autenticação, CSRF, Rate Limiting, ACL
3
Rota direciona para Controller
routes/web.php → Controller@method
4
Controller valida (FormRequest)
Validação de dados, sanitização de input
5
Controller chama Action
Action orquestra a operação, gerencia transações
6
Action chama Service (se necessário)
Lógica de negócio complexa, integrações externas
7
Service/Action interage com Model
Eloquent ORM manipula banco de dados
8
Controller retorna Response
View (HTML), JSON (API), Redirect, Download

Data Flow (Fluxo de Dados)

USER INPUT (Browser/API) ↓ REQUEST (HTTP) ↓ MIDDLEWARE (Auth, CSRF, ACL) ↓ CONTROLLER (Recebe, valida) ↓ ACTION (Orquestra operação) ↓ SERVICE (Lógica de negócio) ← → EXTERNAL API (Integrações) ↓ MODEL (Eloquent ORM) ↓ DATABASE (MySQL) ↓ MODEL (Retorna dados) ↓ ACTION (Processa resultado) ↓ CONTROLLER (Formata resposta) ↓ RESPONSE (View/JSON) ↓ USER OUTPUT (Browser/API)
