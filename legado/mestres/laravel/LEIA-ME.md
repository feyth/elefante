## Como usar em um novo projeto Laravel

### 3 passos. Nada mais.

**Passo 1 — Copie**
Copie TODO o conteúdo desta pasta para a raiz do novo projeto Laravel.

```
seu-projeto-laravel/   ← raiz do projeto
├── .elefante/         ← vem do .mestre-laravel
├── .agents/           ← vem do .mestre-laravel
├── INICIAR.md         ← vem do .mestre-laravel
└── README-ELEFANTE.md ← vem do .mestre-laravel
```

**Passo 2 — Abra o projeto na IA e mande:**
```
leia INICIAR.md
```

**Passo 3 — Programe**
A IA detecta o `composer.json`, lê a stack Laravel, preenche tudo sozinha e avisa quando está pronto.
A partir daí, use `#elefante` no início de cada prompt.
