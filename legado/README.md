# Arquivo Histórico / Legado (v2.x)

Esta pasta contém artefatos históricos das versões 2.x do Framework Elefante, preservados para compatibilidade e referência histórica:

- `mestres/`: Antigos templates monolíticos completos por stack (substituídos na v3.0 pela arquitetura desacoplada em `core/` e `stacks/`).
- `elefante.ps1`: Antigo script PowerShell para Windows (substituído pelo CLI multiplataforma Node.js oficial em `cli/`).

> **Nota:** Para novos projetos e manutenção moderna, utilize sempre o CLI oficial:
> ```bash
> npx @feyth/elefante init
> ```
